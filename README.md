# tripsaver-data

TripSaver(앱인토스 미니앱)가 읽는 공개 데이터예요. JSON 파일만 있어요. 앱은 이 파일들을 데이터로 읽고 검사할 뿐, 실행하지 않아요.

주소: https://beomq.github.io/tripsaver-data/<파일 이름>

| 파일 | 내용 | 출처 | 갱신 |
| --- | --- | --- | --- |
| fx.json | 원화 환율(1단위당 원, JPY_100은 100엔당 원) | 한국수출입은행 현재환율 OpenAPI 매매기준율(AP01) | 평일 11:10, 15:10 KST 자동 (값이 바뀐 경우에만 커밋) |
| benefits.json | 매장, 카드, 카드 행사(혜택) | 혜택마다 source_url(근거)과 event_url(카드사·브랜드 공식 페이지) | 사람이 확인한 뒤 수동 게시 |
| card-fees.json | 카드별 해외 결제 수수료 | 카드마다 sourceUrl(카드사 공식 페이지) | 수동 게시 |
| stores-jp.json | 일본 매장 지점 주소·영업시간 | 지점마다 sourceUrl(체인 공식 페이지) | 수동 게시 |

- 형식이 틀린 파일이 올라오면 앱은 그 파일을 버리고 마지막으로 받은 정상 파일, 그다음 앱에 들어 있는 데이터를 써요.
- 이 저장소에는 비밀값(API 키, 계정 정보)을 넣지 않아요. 수출입은행 인증키는 게시하는 맥에만 있어요.
- 혜택 정보는 참고용이에요. 실제 혜택은 각 카드사 공식 안내를 따라요.
